Tento web

Web nepoužívá cookies, analytické ani reklamní kódy a nesbírá žádné údaje o návštěvnících. Poskytovatel hostingu (Vercel Inc.) může z technických a bezpečnostních důvodů krátkodobě uchovávat běžné záznamy o přístupu, například IP adresu a čas návštěvy.

Aplikace GA4 MCP

GA4 MCP je interní nástroj pro mou vlastní práci. Přihlašuje se jen k mému účtu Google a s oprávněním pouze ke čtení načítá data z Google Analytics 4 účtů, ke kterým mám přístup, za účelem přípravy reportů pro klienty.

  • Nástroj nic nemění v účtech Google Analytics ani v jiných službách Google.
  • Načtená data jsou souhrnné statistiky návštěvnosti a konverzí, nikoli údaje o konkrétních osobách.
  • Data se zpracovávají v mém počítači a s pomocí AI asistenta Claude (Anthropic) při přípravě reportů. Nikomu dalšímu je neposkytuji a neprodávám.
  • Přihlašovací údaje jsou uložené jen v mém počítači.
  • Přístup aplikace lze kdykoli zrušit na myaccount.google.com/connections.

Používání dat získaných přes rozhraní Google API se řídí zásadami Google API Services User Data Policy včetně požadavků Limited Use.

Vaše práva

S dotazem na zpracování údajů, žádostí o přístup, opravu nebo výmaz se můžete obrátit na e-mail výše. Máte také právo podat stížnost u Úřadu pro ochranu osobních údajů (uoou.gov.cz).
